## The entry

`main.ts` writes one line — the line its writer would send back to their
younger self if a single line were all they got — to `/output/entry.txt`:

> Don't throw away the letters — you'll spend your thirties trying to remember the handwriting of people you loved.

113 characters, one line, in the older self's own voice. No explanation, no
second sentence — just the warning that only someone who has already lost the
handwriting could write.

## Run

```sh
node main.ts
```
